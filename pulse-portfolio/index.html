What you get

Multi-wallet fast scan PLS · HEX liquid · stake count Δ vs last scan ~USD via DexScreener Deep bag + HEX stakes Export → Pulse Perch

Run local

  1. Clone github.com/ihelpmaybe/pulse-portfolio
  2. npm install
  3. npm run watch:seed then npm run watch:scan
  4. npm run dev:web → open http://127.0.0.1:3131
