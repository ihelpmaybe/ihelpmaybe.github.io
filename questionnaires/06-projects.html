PulseChain Network — Projects

Job: Project as entity
Founder hunt: What is real, what is missing, and whether this is a customer, partner, or corpse.

Include: 00-contact-stub.md

Must

1. Project name / working title

2. Purpose — what problem, for whom?

3. Missing resources / people / capabilities

4. Who should apply / what help do you want?

Support

5. Stage

6. Current bottlenecks

7. Next milestones

8. Resources the project already has

High-ROI founder asks (add)

9. Do you have paying users, waitlist, or neither?

10. Chain / wallet assumptions (where it lives; what wallets you support or refuse)

11. What coins or assets does the user need to hold or use for this to matter?

12. Revenue so far: none · pre-revenue but committed capital · revenue (band OK) · prefer not to say

13. Biggest competitor or substitute people use instead (including “do nothing”)

14. If you vanished for 90 days, does this project keep moving? Who runs it?

Why these ROI

  • Paying vs waitlist vs neither = reality filter.
  • Wallet/chain/asset assumptions = distribution + integration map.
  • Substitute “do nothing” = true competition.
  • Bus factor = whether to invest intros or walk away.
