PulseChain Network — Unblock

Job: Acute stuck → route help (or product) now
Founder hunt: What stops action — and is it a one-off intro or a product we should build?

Include: 00-contact-stub.md

Must

1. What are you blocked on? (one concrete stuck point)

2. What does “unblocked” look like? (verifiable outcome)

3. Urgency — Today / ASAP · This week · This month · No rush

Support — routing

4. Blocker type (check all)

- Need an intro / relationship
- Need a builder / skill
- Need capital or a deal structure
- Need a decision / sign-off
- Technical / product
- Ops / logistics
- Distribution / customers
- Legal / compliance
- Missing info / research
- Motivation / focus / priority

5. Who or what kind of person could unblock this?

6. What have you already tried?

7. Related project name or link (optional)

High-ROI founder asks (add)

8. Is this block mostly: money · skill · people · tools/UX · trust/fear · time · rules/legal?

9. Have you paid (or tried to pay) anyone to solve this already? What happened?

10. If a tool fixed this tomorrow, what would you pay for the first month? (rough range OK — not net worth)

11. How many other people do you know with this same block? (0 / a few / many / whole community)

Why these ROI

  • Recurring block + many peers = product. One-off + need intro = matchmaking.
  • Prior spend = validated demand.
  • Willingness-to-pay range = pricing smoke test without doxxing bags.
